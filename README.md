# 🚀 Featured Project

<div align="center">

## 🐞 BUG//HUNT

### `FIND IT. BREAK IT. FIX IT.`

**A cyberpunk software-testing mini-game built with Python & Flask.**

</div>

You play as a junior QA operative at **NEXUS SYSTEMS**, investigating intentionally broken applications and filing defect reports.

Instead of another boring testing dashboard, BUG//HUNT turns software testing into an interactive game.

### 🎮 What you can do

```text
🔐 Investigate broken authentication
🌐 Hunt API defects
🧮 Find calculator edge cases
📝 Discover validation failures
🔄 Detect illegal state transitions
📊 Identify malformed data
👻 Reproduce UI behaviour bugs
💀 Solve the Final Defect
```

### ⚙️ Under the Hood

### 🧪 Testing

**57 pytest tests** cover:

- API health & routing
- Mission loading
- Invalid inputs
- Answer validation
- Scoring & combo logic
- Lives & game-over states
- Diagnosis matching
- Leaderboard validation
- Input abuse cases
- Score injection attempts

### 🔐 Engineering Details

- Server-side game state
- Server-side score calculation
- Server-side mission timing
- Answers kept off the client
- Parameterized SQL queries
- Input validation
- Anti-cheat protections
- REST API architecture
